## 1. 产品概述

### 1.1 背景
越来越多外籍人才在中国企业工作、或与中国客户 / 供应商打交道、或负责中国市场拓展。他们的核心痛点不是“认识多少汉字”，而是**在真实商务场景里能不能把话说得清楚、得体、专业**。传统语言 App（背单词、刷语法）与“能在职场开口”之间存在巨大鸿沟。

### 1.2 产品定位
一款 **AI 主导学习路径**的商务汉语学习 App：由一个果冻小人 IP 形象 **LUMI** 全程陪伴，用**对话式引导 + 真实商务场景陪练**的方式，帮全球用户把“中文沟通”拆成一个个可即学即练的场景。

一句话定位：**“你的 AI 商务汉语搭子，帮你把在中国工作的每一次沟通都搞定。”**

### 1.3 目标用户
| 用户类型 | 描述 | 典型诉求 |
| --- | --- | --- |
| 在华工作的外籍员工 | 在中企任职 / 即将入职 | 面试、周会汇报、与同事沟通、入职流程 |
| 对接中国的海外商务人士 | 与中国客户 / 供应商打交道 | 展会介绍、报价谈判、接待来访、对货期 |
| 出海中国市场负责人 | 拓展中国业务 | 来华出差、见经销商、市场调研、路演 |
| 自我提升者 | 个人发展，想提升商务中文 | 自我介绍、寒暄、敬酒、微信沟通 |

主要使用语言为**英语等非中文界面**（产品面向全球用户），被教学的内容始终是中文。

### 1.4 价值主张
- **场景化**：直接练真实工作场景，而非孤立的单词语法。
- **AI 陪练**：LUMI 角色扮演对话、实时发音/得体度打分、即时纠错提示。
- **零压力 onboarding**：用聊天的方式了解用户，几步就能开始第一次对话。
- **随时召唤**：首页任意位置都能唤起 LUMI（下拉手势 / 召唤条 / 底部 Tab）。
- **个性化**：按“学习目的 + 所在行业”推荐可直接开始的场景。

## 5. 核心功能需求

> 每个功能模块包含：目标、详细行为、交互/边界、对应原型。完整用户故事与验收标准见 [FRD](./FRD.md)。

### 5.1 首次进入 · 对话式 Onboarding

**目标**：用最轻量、最像聊天的方式了解用户，并尽快让其开始第一次场景对话。

#### 5.1.1 LUMI 登场（原型：`welcome`）
- LUMI 大图浮动出现，多语言打招呼（Hi! 你好! こんにちは!）+ 一句话自我介绍。
- 主 CTA：「Say hi to LUMI」进入聊天。

#### 5.1.2 问名字（原型：`ask_name`，Step 1/4）
- LUMI 以聊天气泡提问“该怎么称呼你？”。
- 输入框（可自由输入）+ 快捷示例名字 chip。
- **后端需记录用户名字**，之后所有界面按名字称呼（如 “Hi, Alex”）。
- 文案提示“已保存到你的资料”。

#### 5.1.3 选讲解语言（原型：`ask_language`，Step 2/4）
- 选择 LUMI 的**讲解语言**：English / 中文 / 日本語 / 한국어 / Español / Français（可扩展）。
- **记录选择，且从这一步之后所有界面文案均切换为所选语言**（i18n，见 §6）。
- 明确说明：**被教学的中文内容始终是中文，仅界面与点评翻译。**

#### 5.1.4 学习目的（原型：`ask_purpose`，Step 3/4）
- 气泡选项（单选）：
  1. 在华工作（Working in China）
  2. 对接中国客户·供应商（Chinese clients & suppliers）
  3. 进入中国市场（Entering the China market）
  4. 个人发展（Personal growth）
- 记录用于后续场景推荐。

#### 5.1.5 所在行业（原型：`ask_industry`，Step 4/4）
- 问题：“您目前从事于什么行业？”
- 选项（11，单选）：新能源汽车、光伏/新能源设备、通信/硬件、跨境电商、互联网/游戏、基建/工程/建筑、矿业/资源、消费品/零售、职业教育、金融科技、其他。
- 记录用于**行业相关场景推荐**（见 §5.5.1 练场景）。

#### 5.1.6 推荐可直接开始的场景（原型：`recommend`）
- LUMI 一句话引导：“这几个现在就能开练 👇”。
- 按“学习目的”**随机推荐** 3 个**可立即开始**的场景卡（如：模拟面试、展会产品介绍、来中国出差），每张含标题、中文场景名、一句话说明、标签（领域/难度/时长）、▶ 开始。
- 支持「🎲 换一批」重新随机。
- **底部“上划查看更多场景”手势入口** → 进入传统首页。
- 点任意场景卡：**当前版本暂不跳转**（场景对话已暂移除，见 §5.2）。

### 5.2 场景对话与通关结算（本版本暂移除）
> 🚧 **本版本已移除**“核心体验 · 场景对话（原 `chat`）+ 通关结算（原 `summary`）”，将作为独立模块后续单独设计。
>
> 原设想（保留备查，后续重做）：场景对话为 AI 角色扮演，消息含拼音 + 中文 + 界面语言译文 + 发音评分 + LUMI 实时提示 + 建议回复 + 文本/语音输入；完成后进入通关结算（评分、解锁表达、下一步建议）。
>
> 影响：目前所有指向“开始对话”的入口（推荐场景卡、首页快速磁贴、行业热门场景卡、练一个场景卡片、课程页 CTA 等）作为占位保留，暂不触发跳转。

### 5.4 传统首页（原型：`home`）
首页让 **AI 助手 LUMI 全程突出、随时可唤起**，提供三处入口：

1. **顶部下拉手势召唤**（核心交互）：顶部有“下拉，和 LUMI 开始聊天”把手；**按住下拉**会让 LUMI 聊天面板从顶部跟手滑下，拉过阈值松手即展开为完整对话，未到则回弹；轻点也可打开。
2. **中部召唤条**：LUMI（思考表情）+ 示例问题气泡（如“如何礼貌地催别人回复消息？”）+ 圆形箭头，点击进入助手对话。
3. **底部首位 Tab**：LUMI（紫色高亮），始终可点。

首页其余内容（参考成熟学习类首页结构）：
- 顶部：问候（Hi, {名字}）+ 当前“学习焦点”（基于学习目的）+ 通知铃。
- **快速开练磁贴**（2×2）：来中国出差 / 模拟面试 / 展会介绍 / 周会汇报，点击直接进入对话。
- **行业热门场景**：图卡网格，含场景名与“XX,XXX 人在学”。

### 5.5 召唤 LUMI 助手（原型：`assistant` 及其模式）
唤起后 LUMI 先问 **“今天想做点什么？（What do you feel like to do today?）”**，提供 3 个快捷选项，**下方同时提供自由文本输入框与语音输入**，用户可不走选项直接输入。

#### 5.5.1 练一个场景（原型：`asst_practice`）
- 在对话中即时给出场景卡片：**通用场景 + 用户所在行业相关场景**（行业卡带行业标签）。
- 通用场景从场景库随机抽取；行业场景按 §5.1.5 所选行业生成（如“新能源汽车 · 客户拜访 / 产品技术介绍”）。
- 点卡片 → 直接进入场景对话（`chat`）。

#### 5.5.2 翻译一句话（原型：`asst_translate`）
- 选择后向 AI 发送“翻译”指令，LUMI 进入翻译模式并给出示例：
  - 展示「你说的话（界面语言）→ 中文（拼音 + 汉字）」。
- 用户可在下方输入框继续输入任意句子进行翻译。

#### 5.5.3 今天学点什么（原型：`asst_learn`）
- LUMI 结合“目的 + 行业”给出今日可学要点（如：微信礼貌催回复、委婉说“不”、电话里说清数字报价）。
- 提供**一个跳转课程的链接**（当前为占位）→ 课程页 `course`。

#### 5.5.4 自由输入 / 语音
- 文本输入框 + 🎙 语音按钮在所有助手模式下常驻，支持自由提问（原型为展示态）。
- 顶部/底部提供 3 个快捷指令的切换条，便于在练场景 / 翻译 / 学什么之间切换。

### 5.6 课程页（占位，原型：`course`）
- 课程 banner（标题、课时数/时长、进度条与完成度）。
- 课程目录（含已完成 ✅ / 进行中 ▶️ / 未解锁 🔒）。
- CTA：继续学习。
- 说明：当前为**假数据占位**，用于打通“今天学什么 → 课程”跳转，后续接入真实课程内容。

### 5.7 场景库（原型：`library`）
- 搜索框（按场景搜，如“面试”“报价”）。
- 按场景分类（差旅出行 / 会议汇报 / 展会社交 / 商务谈判 / 商务宴请 / 邮件·微信）。
- “为你推荐”场景卡（可换一批）。

### 5.8 我的（原型：`profile`）
- LUMI 作头像、用户名、等级（如 HSK 3 冲刺 · Lv.6）。
- 统计：连续天数、通关场景、累计经验。
- 能力雷达（商务词汇 / 听力 / 口语 / 得体礼仪）。
- 成就墙。
- 设置入口：学习目标与水平、学习语言、提醒与打卡、设置。

## 6. 多语言（i18n）需求
- 用户在 onboarding 第 2 步选择**讲解语言**，**自该步起所有界面文案随之切换**。
- 原型已实现：**English / 中文 完整**；其余语言**回退英文**（产品化时补全）。
- **教学语料恒为中文**：场景对话中的中文句子、拼音始终保持；仅“界面 UI / 译文 / LUMI 点评”随语言切换。
- 场景标题等采用“界面语言标题 + 中文场景名”的双标展示；当界面语言为中文时自动去重。

## 9. 非功能需求
- **性能**：首屏可交互 < 2s；对话往返反馈（产品化接入 AI 后）目标 < 2s 首字。
- **兼容**：移动端为主（iOS / Android，竖屏），手势支持触屏与鼠标（原型用 Pointer 事件实现）。
- **可访问性**：按钮可点区域 ≥ 44px；关键操作有文字标签。
- **合规与隐私**：名字等个人信息需取得同意并安全存储；麦克风权限按需申请。
- **可维护**：文案集中在 `i18n.js`、场景与脚本在 `screens.js`、形象在 `avatars.js`，便于替换为接口数据。
