# BizChinese · 商务汉语 — 产品原型 (Prototype)

面向**全球在中企工作 / 有商务汉语学习需求**的用户的一套 **AI 主导学习路径**的 App 原型图。
本仓库是一套**可点击的高保真交互原型**（纯 HTML / CSS / JS，零依赖），用于辅助后续开发与评审。

> 产品定位：用「AI 小助手 + 真实商务场景对话」的方式，帮在华工作的伙伴搞定中文沟通。
> 设计风格：fancy 的 AI 质感 —— 深色渐变、玻璃拟态、暖金点缀（中文）+ 现代靛紫（AI）。

---

## 🚀 快速预览

无需安装任何依赖，任选其一：

```bash
# 方式一：直接用浏览器打开
open index.html          # macOS
# 或在文件管理器中双击 index.html

# 方式二：起一个本地静态服务（推荐，hash 路由更稳）
python3 -m http.server 8123
# 然后访问 http://localhost:8123/index.html
```

- `index.html` —— **原型总览**：所有界面以手机样机平铺，按流程分组，点击任意一屏进入交互。
- `prototype.html` —— **交互原型**：在手机框里按真实路径点击流转，支持顶部下拉跳转到任意界面、`重新体验`。
  - 可深链到指定界面，例如 `prototype.html#chat`。

## 🧭 首次进入路径（核心 Onboarding 流程）

完全按需求实现，并按用户回答**实时分流 + 生成推荐**：

```
① 选择小助手  →  ② 来中国的阶段  →  ③ 分支提问  →  ④ AI 准备场景  →  ⑤ 推荐场景  →  ⑥ 开始对话
```

1. **欢迎 · 选小助手**：两个形象（小语 / 阿龙）出场自我介绍，用户选一个作为专属 AI 小助手。
2. **Q1 · 阶段**：「你是第一次来中国，还是已经在这边工作了？」（气泡选项）
   - **刚到中国** → **Q2a · 最头疼的事**：出行和日常（差旅）/ 跟同事开会沟通（汇报）/ 参加展会见客户（展会）
   - **工作一段时间了** → **Q2b · 行业选择**：制造 / 互联网 / 金融 / 外贸 / 消费 / 其他
3. **AI 准备场景**：形象说「好，我帮你准备了几个场景，先试一个？」（生成动画 + 清单）
4. **推荐场景列表**：根据上面的回答**动态生成** 3 个场景卡片。
5. **场景对话**：点击场景直接开练 —— AI 角色扮演 + 拼音/翻译 + 实时发音打分 + 小助手实时提示。

## 🗂️ 目录结构

```
.
├── index.html              # 原型总览（gallery）
├── prototype.html          # 交互原型（手机框 + 可点击流转）
└── assets
    ├── css
    │   ├── tokens.css       # 设计 token（颜色/圆角/阴影/字体）
    │   ├── app.css          # 手机框 + 所有界面组件样式
    │   └── gallery.css      # 总览页 + 交互页外壳样式
    └── js
        ├── avatars.js       # 两个 SVG 形象（小语 / 阿龙）
        ├── screens.js       # 所有界面模板 + 分支生成逻辑（单一数据源）
        ├── flow.js          # 交互原型的状态与点击流转
        └── gallery.js       # 总览页的样机平铺渲染
```

> 设计要点：所有界面在 `screens.js` 里以 `render(state)` 函数定义，**总览页与交互页共用同一套界面代码**，保证两处始终一致、易维护。

## 🎨 设计系统速览

- **品牌渐变**：`#6D5EF8 → #9A4FF0 → #FF6FB5`（AI 沉浸感）
- **暖金点缀**：`#FFD479 → #FF9F45`（中文气质 / 高亮）
- **形象**：小语（青绿·耐心陪练）、阿龙（金橙·实战搭子），均为内联 SVG，可随时替换为插画/3D。
- **手机框**：390 × 844（iPhone 比例），圆角刘海样机。

## 🛠️ 给开发的对接建议（Next）

- 文案、场景数据、形象资源均集中在 `screens.js` / `avatars.js`，便于替换为接口数据。
- 推荐场景目前为前端按分支生成的样例数据，后续可对接 **AI 推荐 / 对话生成接口**。
- 对话评分、能力雷达、连续打卡为展示态，接入后端后即可数据化。
