# BizChinese · 商务汉语 — 产品原型 (Prototype)

面向**全球在中企工作 / 有商务汉语学习需求**的用户的一套 **AI 主导学习路径**的 App 原型图。
本仓库是一套**可点击的高保真交互原型**（纯 HTML / CSS / JS，零依赖），用于辅助后续开发与评审。

> 产品定位：由果冻小人 IP 形象 **LUMI** 带着，用「对话式 onboarding + 真实商务场景陪练」的方式，帮在华工作的伙伴搞定中文沟通。
> 设计风格：fancy 的 AI 质感 —— 深色渐变、玻璃拟态、暖金点缀（中文）+ 现代靛紫（AI）。

## ✨ IP 形象 · LUMI

单一的果冻 / 软糖小人形象（类泡泡玛特 IP，**非人形**），半透明、会发光、Q 弹可爱，作为唯一的 AI 小伙伴贯穿全程：登场自我介绍、对话式引导、首页随时召唤。SVG 内联实现（`assets/js/avatars.js`），含 happy / wink / think 三种表情，可随时替换为正式插画 / 3D。

## 🚀 快速预览

无需安装任何依赖，任选其一：

```bash
# 方式一：直接用浏览器打开
open index.html          # macOS
# 或在文件管理器中双击 index.html

# 方式二：起一个本地静态服务（推荐，hash 路由更稳）
python3 -m http.server 8123
# 然后访问 http://localhost:8123/index.html
```

- `index.html` —— **原型总览**：所有界面以手机样机平铺，按流程分组，点击任意一屏进入交互。

  - 可深链到指定界面，例如 `prototype.html#chat`。

## 🧭 首次进入路径（对话式 Onboarding）

完全按需求实现，LUMI 用聊天的方式一步步引导，并按回答**实时随机推荐**：

```
① LUMI 登场  →  ② 问名字  →  ③ 选学习语言  →  ④ 学习目的  →  ⑤ 随机推可直接开始的场景  →  ⑥ 开始对话  →  ⑦ 上划进首页
```

1. **LUMI 登场**：果冻小人 LUMI 出现，打招呼 + 自我介绍。
2. **聊天 · 问名字**：进入聊天环节，LUMI 询问用户名字（后端记录，后续按名字称呼）。
3. **聊天 · 选学习语言**：选择 LUMI 的讲解语言并记录，**后面的提问就用所选语言**（界面已做 i18n，英 / 中完整，其它语言回退英文）。
4. **聊天 · 学习目的**：在华工作 / 对接中国客户·供应商 / 进入中国市场 / 个人发展。
5. **可直接开始的场景**：根据目的**随机推荐**可立即开练的场景（如：模拟面试、展会产品介绍、来中国出差…），可「换一批」；底部显示**上划查看更多场景**。
6. **场景对话**：点击场景直接开练 —— AI 角色扮演 + 拼音/翻译 + 实时发音打分 + LUMI 实时提示。
7. **传统首页**：上划进入传统首页，**顶部是 LUMI 头像 + 对话框的召唤入口**，提醒用户随时点它召唤 LUMI 开启对话（底部 Tab 中央也是 LUMI）。

> 多语言：用户在第 ③ 步选定的语言会驱动之后所有界面文案（演示默认 English，体现“全球用户”定位）；**被教学的中文内容始终保持中文**，只翻译界面与点评。

## 🗂️ 目录结构

```
.
├── index.html              # 原型总览（gallery）
├── prototype.html          # 交互原型（手机框 + 可点击流转）
└── assets
    ├── css
    │   ├── tokens.css       # 设计 token（颜色/圆角/阴影/字体）
    │   ├── app.css          # 手机框 + 所有界面组件样式
    │   └── gallery.css      # 总览页 + 交互页外壳样式
    └── js
        ├── avatars.js       # 果冻小人 IP 形象 LUMI（内联 SVG，3 种表情）
        ├── i18n.js          # 可选语言 + en/zh 文案字典（讲解语言切换）
        ├── screens.js       # 所有界面模板 + 场景数据 + 对话脚本（单一数据源）
        ├── flow.js          # 交互原型的状态与点击流转
        └── gallery.js       # 总览页的样机平铺渲染
```

> 设计要点：所有界面在 `screens.js` 里以 `render(state)` 函数定义，**总览页与交互页共用同一套界面代码**，保证两处始终一致、易维护。

## 🎨 设计系统速览

- **品牌渐变**：`#6D5EF8 → #9A4FF0 → #FF6FB5`（AI 沉浸感）
- **暖金点缀**：`#FFD479 → #FF9F45`（中文气质 / 高亮）
- **形象 LUMI**：果冻 / 软糖小人（非人形），半透明发光、Q 弹，内联 SVG，可随时替换为插画/3D。
- **手机框**：390 × 844（iPhone 比例），圆角刘海样机。

## 🛠️ 给开发的对接建议（Next）

- 文案在 `i18n.js`、场景与对话脚本在 `screens.js`、形象在 `avatars.js`，均便于替换为接口数据。
- **后端需记录**：用户名字、所选讲解语言、学习目的（onboarding 三步），用于个性化称呼与推荐。
- 推荐场景目前为前端按「目的」随机生成的样例数据，后续可对接 **AI 推荐 / 对话生成接口**。
- 对话评分、能力雷达、连续打卡为展示态，接入后端后即可数据化。
